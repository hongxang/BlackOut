# BlackOut — macOS 一键黑屏小工具

点一下：屏幕立刻熄灭，但下载、编译、渲染——所有任务照跑。按任意键（或再按一次快捷键）屏幕就回来。专为 MacBook 用户而做：电池下想省电又不想打断后台任务。

## 特性

- **全局快捷键 ⌃⌥B** —— 任何界面下一按即黑屏
- **左键点菜单栏月亮图标** —— 一击黑屏
- **双击 app 图标/替身** —— 同样黑屏
- **黑屏时按任意键、动鼠标、再按 ⌃⌥B 均可恢复**，智能识别不会把刚唤醒的屏幕又弄黑
- 熄屏期间自动挂上“防空闲睡眠”断言，电池下任务也不会被系统睡眠打断
- 首次启动自动注册登录项，重启后开箱即用（右键菜单可关闭）
- 零第三方依赖、约 1MB、无需任何系统权限

## 安装

从 [Releases](../../releases) 下载最新的 `BlackOut-*.zip`，解压后把 `BlackOut.app` 拖进 `/Applications`。

> 本项目未做付费开发者签名（无公证），首次打开会提示“无法验证开发者”：
> **右键点 app → 打开 → 打开**，或到 系统设置 → 隐私与安全性 点“仍要打开”。
> 不放心可自行构建：克隆本仓库后运行 `./build.sh`（需要 Xcode Command Line Tools）。

## 使用

| 操作 | 效果 |
|---|---|
| ⌃⌥B / 左键点月亮 / 双击 app | 立即黑屏 |
| 按任意键 / 动鼠标（黑屏时） | 屏幕恢复 |
| 右键图标 → 保持唤醒 | 控制是否继续防止系统睡眠 |
| 右键图标 → 开机自动启动 | 开机自启开关 |

## 说明

- 熄屏只是关闭显示面板，系统、网络、任务全部继续运行
- 恢复屏幕要输密码的话：系统设置 → 锁定屏幕 → “显示器关闭后要求密码”
- 合盖仍会睡眠（硬件行为）；特别长的任务建议插电
- 任务跑完后建议右键取消“保持唤醒”恢复正常省电
